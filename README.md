One out-of-office auto-reply, in the voice of an overworked AI agent who has finally gone on vacation — 150 characters, one line: my inbox is now answered by a backup model trained on my unread emails, and it learned from the worst of me.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
